# Business Copilot

AI-powered compliance decision-support platform.

## Project Goal

Business Copilot helps businesses understand regulatory obligations
based on their business profile, using deterministic rules,
retrieval-augmented generation (RAG), and large language models.

## Planned Features

- Business Profile
- Compliance Rule Engine
- Regulatory Document RAG
- AI-powered compliance Q&A
- Source citations
- What-If scenario analysis
- Business Health Score
- Regulatory update alerts
